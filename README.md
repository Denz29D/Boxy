# Boxy

Boxy is an Android boxing and fitness application that I independently designed and developed as part of a university software development project.

The app was created to support users with boxing training, workout tracking and fitness-related activities through a mobile interface.

## Features

- Push-up tracking
- Workout and exercise tracking
- Training timers
- Fitness and boxing videos
- Map functionality
- User account functionality
- Progress tracking
- Exercise and workout management

## Technologies

- Kotlin
- Android Studio
- Gradle
- Android SDK
- Google Maps integration

## What I Built

I was responsible for the full development of the application, including the app structure, feature implementation, interface development and integration of the different fitness and training functions.

## What I Learned

This project gave me practical experience with:

- Android application development
- Kotlin programming
- Mobile UI development
- Application architecture
- Integrating external services
- Debugging and testing
- Version control with Git and GitHub

The project strengthened my ability to take a software idea from initial development through to a working mobile application.
